usage:
  ./expat/xmlwf/xmlwf [OPTIONS] [FILE ...]
  ./expat/xmlwf/xmlwf -h|--help
  ./expat/xmlwf/xmlwf -v|--version

xmlwf - Determines if an XML document is well-formed

positional arguments:
  FILE           file to process (default: STDIN)

input control arguments:
  -s             print an error if the document is not [s]tandalone
  -n             enable [n]amespace processing
  -p             enable processing of external DTDs and [p]arameter entities
  -x             enable processing of e[x]ternal entities
  -e ENCODING    override any in-document [e]ncoding declaration
  -w             enable support for [W]indows code pages
  -r             disable memory-mapping and use [r]ead calls instead
  -g BYTES       buffer size to request per call pair to XML_[G]etBuffer and read (default: 8 KiB)
  -k             when processing multiple files, [k]eep processing after first file with error

output control arguments:
  -d DIRECTORY   output [d]estination directory
  -c             write a [c]opy of input XML, not canonical XML
  -m             write [m]eta XML, not canonical XML
  -t             write no XML output for [t]iming of plain parsing
  -N             enable adding doctype and [n]otation declarations

billion laughs attack protection:
  NOTE: If you ever need to increase these values for non-attack payload, please file a bug report.

  -a FACTOR      set maximum tolerated [a]mplification factor (default: 100.0)
  -b BYTES       set number of output [b]ytes needed to activate (default: 8 MiB)

reparse deferral:
  -q             disable reparse deferral, and allow [q]uadratic parse runtime with large tokens

info arguments:
  -h, --help     show this [h]elp message and exit
  -v, --version  show program's [v]ersion number and exit

exit status:
  0              the input files are well-formed and the output (if requested) was written successfully
  1              could not allocate data structures, signals a serious problem with execution environment
  2              one or more input files were not well-formed
  3              could not create an output file
  4              command-line argument error
